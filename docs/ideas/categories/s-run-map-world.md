## Approved ideas
- S1 Rival Gauntlet: a mid-run lane where each fight is a past-run ghost of your own team.
- S2 Tide Clock: a day/night/tide counter that changes encounters and shop stock per map node.
- S6 Run Modifiers Draft: pick 1 of 3 run-wide rules at start (Glass Cannon, Marathon, Frugal).
- S9 Landmark Nodes: once-per-run named locations (Pokémon Tower, Power Plant) with unique mini-dungeons.
- S10 Convoy Mode: escort an NPC across the map; their HP is a second resource.
- S11 Multi-Region Runs: a run chains 2–3 regions with a boss at each border.
- S13 Run Seeds Library: share and replay named seeds with a leaderboard of results.
- S14 Endless Tower: post-win infinite floor climb with escalating modifiers.
- S16 Daily Run: one fixed seed per day with global rank, same rules for everyone.
- S17 Weekly Mutator Run: a rotating ruleset (no items, mono-type, only evolved).
- S20 Time Pressure Mode: an optional run clock; slower runs lose bonus rewards.
- S22 Dungeon Floors: some nodes open into 3-room dungeons with traps and loot.
- S132 Global Calendar Events: real-date festivals with exclusive rewards.
- S133 World Boss Week: everyone fights the same boss with shared damage totals.
- S134 Meteor Showers: node-wide event spawns rare stardust Pokémon.
- S135 Migration Seasons: species relocate across regions by season.
- S136 Festival Stops: music, food and minigames as optional rest nodes.
- S137 Eclipse Events: darkness boosts Dark/Ghost and hides map info.
- S138 Legendary Sightings: rumor chains ending in a pre-boss encounter.
- S139 Trading Post Days: a village node where you swap with AI traders.
- S140 Disaster Nodes: earthquake, flood or blizzard modifies the whole next stretch.
- S141 Hidden Grotto Network: grottos connect across the map as teleports.
- S142 Pokémon Contest Nodes: judged style challenges that pay accessory items.
- S143 Ranger Missions: capture-and-release tasks for reputation.
- S144 Wandering Merchant Lines: merchants return on a route you can predict.
- S145 Haunted Mansion Dungeon: a puzzle dungeon with lamps and ghosts.
- S146 Underwater Dive Nodes: scuba sections with oxygen and rare water mons.
- S147 Sky Route: airborne nodes available only with certain Pokémon.
- S148 Cave-In Events: pick a mon to tunnel through for treasure.
- S149 Rival Ambush: a surprise battle that skips a map node if you flee.
- S150 Treasure Hunt Season: a map piece set across five runs.
- S151 Mysterious Egg Delivery: carry an egg without battling too long.
- S152 Lighthouse Beacon: lit beacons boost your next three nodes.
- S153 Weather Control Tower: choose tomorrow's weather at the cost of power.
