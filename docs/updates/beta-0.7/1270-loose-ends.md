# 0.6 loose ends (workstream 3)

- **Player gets:** Settings > Gameplay rows for the Extended Cut (off by default), story event density (Low/Normal/Full) and Kanto story spaces. Four new Team Rocket raid doors in Kanto, drawn from ordinary event stops when you face Rocket: Mt. Moon Fossil Dig (Raid 1), Pokémon Tower (Raid 3), Vermilion Docks (Raid 4, after Raid 2) and Safari Night (Raid 5, after Raid 3 or track step 4). Each is a two-step fight chain with a boss finale, a sabotage option and a "stay out" option, and resolves the real story raid result once. The Snorlax Blockade event has a "Shout to wake it" choice: it listens on the microphone if Settings > Controls > Microphone is on, and a button press does exactly the same thing.
- **Save:** none. The 11 unread placeholder settings (`climaxSecondShot`, `rivalOverhaul`, `rivalFriend`, `secondChancePct`, `healsPerBattle`, `revivesPerBattle`, `blessingsEnabled`, `mythicalsEnabled`, `ultraBeastsEnabled`, `wholeRunEventsPct`, `whatIfCasts`) were removed from the settings schema. Zod drops unknown keys, so old saves load unchanged (tested); no version bump, so it does not collide with settings v43. Heal/revive caps stay in `balance.json` `itemCaps`; Second Shot stays always on. A later system that needs one of these names adds it back.
- **Limits:** the doors are short fight chains, not the full raid format with floors and objectives; Raid 3 has no failure list and the Hostage cost is still unbuilt. The shout screen is the only mic user so far (rhythm and cheer games later). The Extended Cut is Kanto only and not balanced, hence off by default.
