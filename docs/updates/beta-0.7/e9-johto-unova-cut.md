# E9: Extended Cut for Johto and Unova

**Player gets:** with the Extended Cut on, the Johto and Unova climaxes use the Extended Cut director like Kanto, Alola, Paldea, Kalos and Galar: Gauntlet, Duels, Breather (save point), Set piece, Boss, and Second Shot on a loss.

**Save:** none (the climax region is already stored in `run.expansion.cut`).

**Limits:** Siege Map, Blackout, Colossus (Dark Celebi), Convoy (Unova) and Front have only Kanto content, so they skip themselves in these regions (`canStart`). Johto's closing duel and Unova's Convoy are not built. Raids 4 and 5 belong to the loose-ends thread.
