# Evil Team: The Betrayal

- After you beat an Evil Team's leader, a "THE BETRAYAL" card plays: the Legendary the team chased turns on its master (skippable, shorter on replay, off with animations off).
- You catch it through the team's existing "A Legend Stirs" stop (a wild, catchable battle that opens once the team is defeated).
- Limit: "A Legend Stirs" is a rare stop, so it is not guaranteed to come right away. The Legendary Awakening scene is not built yet.
- Presentation only: no save change.
