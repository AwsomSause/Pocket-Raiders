# Starting trainers: Red, Blue, Green, Hilda, Nate

- Trainer select offers exactly these five (plus the Trainer Evolution of each). Everything else stays in the data for old saves and stats. Old saves naming another trainer map to one of the five.
- Hilda and Nate are rebuilt as a mirrored pair, both unlocked from the start (no more unlock grind):
  - **Hilda, The Spark:** first attack +30%, later attacks -5%; fire moves +15%; +10% crit chance; takes 5% more damage. Signature: Emboar, Chandelure, Volcarona, Reshiram.
  - **Nate, The Anchor:** first attack -5%, later attacks +15% (nerfed from +30%); water moves +15%; party heals 5% after each battle; takes 5% more damage. Signature: Samurott, Jellicent, Seismitoad, Zekrom.
- Prologue Look step shows all five previews. Supersedes the Nate/Hilda-only note in `player-sprites.md`.
- Also fixed: a save made in the middle of a nemesis battle (a boss's ace coming back) was wrongly rejected as corrupt ("Unknown trainer class gym-leader"). The save check now accepts boss classes.
