# Beta 0.5 update-log fragments

Each Beta 0.5 PR adds ONE file here named `<pr-number>-<short-name>.md` (e.g. `1080-galar-shop.md`) and does NOT edit `../beta-0.5.md`. Use this layout:

```
# <PR title> (#<number>)
**Player gets:** one or two plain-language sentences.
**Save:** none, or version bump + migration test name.
**Limits:** what is not done yet.
```

The integration lead compiles the fragments into the final log.
