# Save generator and run import (dev tool)
**Player gets:** "Export save" now also keeps the run in progress, and "Import save from a file" restores it (press Continue afterwards). A dev tool, `node tools/savegen.ts <spec|preset> [out.json]`, builds an importable save from a short JSON spec: any party (species/form, gender, shiny, level, nature, ability, moves, held item or "mega-stone", IVs/EVs, friendship, nickname, Tera type, HP, status), trainer, mode/difficulty, region and stage, money, items, badges, gimmick uses, story/rival flags, and profile progress (Bank, Research, Prestige, Remembrances, unlocks, dex). Blanks are filled from the seed; anything else can be set with `patch` dot-paths. Field list and how to extend: `tools/savegen/README.md`.
**Save:** none (export file gains an optional `run`; older export files still import). Generated files use the current save versions.
**Limits:** full campaign only (not Story Run stage layout); a restored run starts at the beginning of the chosen stage, not mid-map.
