# #1324 New UI: the pause menu on the map and the confirm box

**Player gets:**
- **Esc on the stage map opens the pause menu** from the mock-ups: the map dims and "Paused" stands over six buttons (Resume, Party, Bag, Settings, Save, End run). Arrows and Enter, or a click, pick one; Esc or a click beside the buttons resumes.
- Party, Bag and Save open the same menus the map's own buttons open.
- **Settings can now be opened in the middle of a run.** Its last row is "Back to the map", and the run is exactly where you left it.
- End run works only in an Adventure run (the only mode the game lets you give up from the map). It first opens the mock-up's **confirm box**: "End this run? Your progress is banked as a defeat. This cannot be undone." with the cursor on "Keep playing". Esc keeps playing. In other modes the button is dim and says to use Save instead.

**Save:** none.

**Limits:**
- New look only. In Old the map keeps its side buttons and Esc does what it did.
- Opened from a run, the Save & Data page leaves out Import save, Replay the tutorial, Asset credits and the update log (they swap the profile or leave for another screen). They are still there from the title screen and the Hub.
- The pause menu is on the stage map only, not in a battle, an event or a town.
