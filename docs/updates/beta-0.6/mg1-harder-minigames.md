# MG1: Harder minigames (Master tier)

## Player gets
- The 14 original minigames and the 4 Battle Frontier games each have a fourth **Master** tier: more rounds, tighter windows, more decoys, higher foe levels.
- Master pays 3x the base money (Hard pays 2x) and Frontier Points scale by tier.
- The Minigames difficulty setting (Easy / Normal / Hard) marks "(your setting)" on the matching tier in the picker; Hard points at Master. All tiers stay selectable.
- The other 16 newer minigames keep Easy / Normal / Hard (MG2 will cover new and remade ones).

## Save
No save change. The tier is already a number inside the saved minigame state; same seed + tier replays the same.

## Limits
- "Fewer hints" is only data-driven where a game already has a hint option (Berry Foraging hides rotten berries from Hard up). No new hint systems.
- Master numbers are first-pass; the balance test confirms a random bot never gets gold on most plays, but real play may need tuning.
