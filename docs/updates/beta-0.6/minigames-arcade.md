# Minigames: Arcade cabinets (MG2 batch 4)

**Player gets:** three arcade games: Ball Breaker (paddle and Poké Ball), Snowball Shooter, Berry Stacker. Easy, Normal, Hard; medals and rewards like the others.

**Save:** no change.

**Limits:** rules and data only; plain grid screen until the picked Arcade layout (8) is built, which should use the in-game Poké Ball, snowball and item art.
