# Minigames: Orchestra (MG2 batch 2)

**Player gets:** Orchestra, a rhythm minigame: cue Strings, Brass, Winds and Drums on the beat, plus a Swell cue. The Swell is a button, or a loud sound when mic input is on (the screen sends the same action either way). Easy, Normal, Hard; medals and rewards like the others.

**Save:** no change.

**Limits:** rules and data only; shown on the plain grid screen until the picked Orchestra layout is built. Mic wiring lives in the screen, not the rules.
