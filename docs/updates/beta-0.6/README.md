# Beta 0.6 per-PR notes

Each PR into `beta-0.6` adds one file here named `<pr>-<short-name>.md` with three headings:

- **Player gets:** what a player can now do or see.
- **Save:** save versions bumped (with the migration test), or "none".
- **Limits:** what is stubbed, limited or disabled, and why.

The integration lead merges these into `docs/updates/beta-0.6.md` before the final PR into `main`.
