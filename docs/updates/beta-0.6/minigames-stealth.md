# Minigames: Stealth Escape (MG2 batch 3)

**Player gets:** Stealth Escape (Pokémon Prison / Old Wing style): sneak past patrolling guards to the exit, grab keys for bonus points. Being seen costs an alert and sends you back. Easy, Normal, Hard.

**Save:** no change.

**Limits:** rules and data only; plain grid screen until the picked Stealth layout (9) is built. Guard routes are straight patrols.
