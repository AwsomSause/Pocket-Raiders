# Minigames: new Beta 0.6 games removed

**Player gets:** no new minigames in Beta 0.6 (Kice's call). The 34 existing minigames stay, with the harder tiers from the MG1 remake. The Beta 0.6 minigame work (Snake, Sled, Triage, Orchestra, Stealth, Arcade, Debate, Safari Trek, Safari Land, the arcade cabinet choice and the picture-board screen) was taken out again.

**Save:** no change. Minigame stops pick games exactly as they did before 0.6.

**Limits:** Fuchsia's Safari Land is now a plain event (a paid Safari-pool wild fight) instead of a minigame.
