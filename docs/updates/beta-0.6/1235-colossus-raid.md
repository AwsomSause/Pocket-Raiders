# Colossus is a normal raid

**Player gets:** the Kanto roof fight against M2 is now a multi-phase raid like the Magmuk raid: three shields to break (at 75%, 50% and 25% of its health), a new phase after each, a charged attack every three turns, an extra action when it is low, and a 10 turn timer. The normal raid screen and cheers are used. Win: M2 is broken. Timer out: the helicopter takes it away (the climax still counts). Lose: you fall back and the run goes on.

**Save:** none. The optional `battle.colossus` field is gone (old saves never had it in a live run).

**Limits:** M2's signature moves are not real moves yet; the Rig Room tier drop and Giovanni's delayed order are not built. Details in `docs/status/wide-formats-colossus.md`.
