# Wide formats: Debate (E4, 7 of 7)

**Player gets:** Paldea's Assembly as three exchanges. Put forward evidence you earned (flags or a Key Item) to win each one. Three wins: no battle. Two wins: the other side objects, no battle. Fewer: one battle against Harrow. Losing never ends the run.

**Save:** none (result in `story.flags['star.x.debate']`).

**Limits:** the evidence flags and the brochure item are not given out by anything yet (the Paldea saga slices must set them); plain Format card; Harrow uses a generic Veteran team. Details in `docs/status/wide-formats-debate.md`.
