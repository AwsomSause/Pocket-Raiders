# Minigames: The Day the Center Closed, beds version (Kice's Triage pick)

**Player gets:** a triage game with 3 beds: pick a patient, put them in a bed (stops them getting worse), then use the supply that cures them (Antidote, Burn Heal, Paralyze Heal, Revive). Supplies run out, so worst first. Easy, Normal, Hard; medals and rewards like the others. The earlier pick-and-treat triage stays as an extra.

**Save:** no change.

**Limits:** rules and data only; it uses the plain card grid, not the drag-and-drop paper layout from the pick. Pokémon art on patient cards and nurse Chansey are not drawn yet.
