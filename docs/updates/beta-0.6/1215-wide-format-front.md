# Wide formats: Front (E4, 6 of 7)

**Player gets:** the Giovanni finale fought as lanes on a triple battle (doubles with two lanes). Each lane has its own foe, and you can only hit the foe in your own lane until it falls. Winning sets `finale.x.front = held`; losing is a story loss and the run goes on. Starts only from the Extended Cut director.

**Save:** none (uses `run.expansion.cut`; result in story flags).

**Limits:** only the Kanto lane table exists; uses the plain Format card; needs triple battles on, otherwise it plays as doubles. Details in `docs/status/wide-formats-front.md`.
