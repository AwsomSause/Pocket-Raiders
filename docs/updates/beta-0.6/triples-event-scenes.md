# Triple Battle event scenes

**Player gets:** event fights can now be double or triple battles. **Triple Trouble** is three kids at once, in a triple battle. In **The Whispering Grove**, a new choice, "Wake them", starts a triple battle against three wild Pokémon. **Double Trouble**, **the Twins** and **the Hot Dog Duelists** are now real double battles, as the new events pack describes them.

**Save:** none. The new `format` field is optional in the event data.

**Limits:** triple battles stay off until the triple battle screen (T2) is in, so for now both triple scenes are fought as double battles. A scene drops to doubles if you have only two healthy Pokémon, and to a single battle if you have one.
