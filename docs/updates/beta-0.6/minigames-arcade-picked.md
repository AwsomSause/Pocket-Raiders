# Minigames: Whack-a-Diglett and Claw Machine (the picked Arcade cabinets)

**Player gets:** two arcade games from Kice's Arcade pick: Whack-a-Diglett (tap the Diglett, not the Meowth decoys) and Claw Machine (line up the claw, grab the highest-value prizes). With the existing Pinball Bonus, these are the three cabinets of the pick. Easy, Normal, Hard; medals and rewards like the others.

**Save:** no change.

**Limits:** rules and data only. The picked Rocket Row Arcade cabinet-select screen is not built yet. Plays use the normal two tries per stop, not tokens (tokens would be a new currency, which is on the off list).
