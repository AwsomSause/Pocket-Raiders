# Triple Battles are on

**Player gets:** real triple battles, three Pokémon a side, in the style Kice picked (Triple 2: Essentials Kit boxes with the long foe box).
- Foe boxes stack down the top left and yours down the right.
- Each of your Pokémon gets a command in turn, left to right. Back returns to the one before.
- Edge Pokémon get a **Shift** button to step into the centre.
- When you aim a one-target move, foes it can't reach get an "OUT OF REACH" tag and aren't offered as targets. Targets show their spot (Left / Centre / Right).
- Triple battles now happen in runs:
  - some ordinary trainers from region 3 on
  - the **Triples Only** run rule, which can now be picked
  - the event scenes: Triple Trouble, Whispering Grove, Shadow Triad, Plasma Yard, Delibird, Monster House, Double Booking
  - the Battle Factory's triple format

**Save:** none. Triple battles saved mid-fight load back as triple battles.

**Limits:** you need three healthy Pokémon, or the fight is a double battle. Skins other than the Essentials Kit don't have their own triple layout: triple battles always use the Kit boxes.
