# Minigames: picture boards (MG2 UI slice 1)

**Player gets:** Psyduck Migration, Sled Run and Stealth Escape now draw a picture board of coloured tiles with real game art (berries, snowballs) where the art exists, and the controls sit underneath. Other games look the same as before.

**Save:** no change.

**Limits:** a first step toward the picked layouts (Snake 5, Sled 11, Stealth 9): the board is a tile grid, not the full cabinet or phone frame, and Psyduck, trees and guards are still text tiles. Orchestra 6, Triage 6 and Arcade 8 still use the plain card layout.
