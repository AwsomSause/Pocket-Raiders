# Minigames: Rocket Row Arcade cabinet choice (Kice's Arcade pick)

**Player gets:** when a minigame stop is an arcade game, the player first picks a cabinet (Pinball, Whack-a-Diglett or Claw Machine) from a "Rocket Row Arcade" list that shows each one's best medal, then picks the difficulty as usual. Choosing is free and can be redone until the first try.

**Save:** no change (the choice swaps the stop's game inside the run, before any try).

**Limits:** a list screen, not the full painted cabinet cards from the pick (no cabinet art or token counter; plays use the normal two tries, no tokens). The earlier extra arcade games (Ball Breaker, Snowball Shooter, Berry Stacker) still appear as arcade stops but are not on the cabinet list.
