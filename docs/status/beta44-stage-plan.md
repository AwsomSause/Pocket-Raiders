- **Beta 4.4 bug list, part 5b (next stage built from your run)**: A stage is only decided when the player reaches it. At each new stage, `core/stagePlan.ts` compares the run's counters with a snapshot taken when the last stage began and finds what stood out: catching (2+ caught), fighting (5+ wins with no wipe or heavy healing), exploring (2+ events), spending (₽3,000+ moved) or struggling (a wipe or 2+ heal stops). The strongest two (`balance.stagePlan`) weight the theme (types not caught yet; a tougher matchup for a team winning easily; a kinder one after struggling) and each add one fitting event stop (rare Pokémon / dojo or tower / detour / merchant / rest, plus a heal stop halfway for a team that struggled). The stage banner and the map's item list ("Route plan") say why. With no signal the stage is the same plain pick as before. Fame Checker now names the region's gym leaders still to come, not a fixed order. Determinism: theme stays on the 'map' stream; extra stops use their own seeded generator. Tests: stagePlan, mapMoveItems (Fame Checker). Limits: the first stage of a run has no plan; League stages are not tailored.
