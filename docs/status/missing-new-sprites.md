- **Missing sprites for new Pokémon (2026-11-17):** root cause was the offline service worker (`public/sw.js`): after an update, the first load ran the new game with the old build's cached `assets/manifest.json`, so every new Pokémon (e.g. wild Lapling) drew the blue placeholder circle. The manifest is now fetched network-first. Also: `tools/catalogInputs.ts` now lists the Mega Stone icons from `jetSpecies.json` (63 stones had no icon in the manifest), a first failed art load is retried once (`lazyAssets.ts`, `sprites.ts`).
