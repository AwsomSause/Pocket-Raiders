- Growth slice 9 (ideas S55): Ability Capsule Quests. Six themed trials (Fire, Water, Grass, Electric, Psychic, Dark): win 4 battles with a Pokémon of that type fighting; each pays one Ability Capsule once per run. Camp menu > Camp > "Ability capsule" shows progress and spends a capsule to move a Pokémon to another of its abilities (hidden included). Code `src/core/capsuleQuests.ts`, progress hook in the win path; state in run `itemCounters` (`capq:`, `capq-done:`, `capsules`), no save bump. Tests `tests/unit/capsuleQuests.test.ts`. Design choice: capsules are a counter, not a Bag item, so they never clutter the Bag. Limited: no quest-complete banner on the map (the Camp menu shows it).
