# Node Event Menus core (Beta 0.7, P1-P4)

Setting **Node menus** (`settings.expansion.nodeMenus`, off by default until the P7 sims pass; no settings bump, the field has a default). With it on, a run started outside Boss Rush, Speed Clear and Time Attack gets `run.expansion.nodeMenus` (optional, no run bump). On a stage node the map's **Here** button opens a menu of 2 to 5 cards (weights 30/40/25/5 in `src/data/nodeMenu.json`) under the node's battle: the node's side stops, then short **micro entries** (Forage, Catnap, Odd job, Light spar, Scout ahead, Field notes, Something shiny) so a menu never runs dry. Every menu mixes at least two kinds. One optional pick per node, two on gym-eve, plaza and 5-entry nodes; the other optional cards lock. Story-critical stops (forced, mode, callback, canon, key-item, `xe.*`, milestone, tournament, crisis, plaza, roaming Legendaries) are always open, never trimmed and use no pick. At most 2 required entries (the battle plus one forced, battle-free story event), never two required battles; the map won't move on until it is done. Side stops beyond the menu size are trimmed (hidden while menus are on).

Code: `src/core/nodeMenu/` (`tags.ts` P1 categories for all 959 events, `compose.ts` P3 composer on its own stream `<seed>::node-menu::<stage>::<node>`, `flow.ts`, `hooks.ts` for P5 special entries), screen `src/ui/nodeMenuPanel.ts` (stop-card look, no new art), sim `npm run sim:node-menus`. Tests: `tests/unit/nodeMenus.test.ts`, `tests/e2e/nodeMenus.spec.ts`.

P4 sim (2026-11-14, `npm run sim:node-menus -- 40`, stage pacing on, bot plays one micro entry per node): no errors; battles per run 39.6 off vs 38.5 on (-3%), stages 2.35 vs 2.27. 1,530 menus, 3.07 entries each (sizes 2/3/4/5: 29/39/26/5%); every menu has 2+ kinds. Entries are 22% side stops and 78% micro; 48% of menus have no side stop (micro only), so micro entries carry the menus as the plan expected. 0.02 side stops trimmed per menu; 1.13 picks per menu. Limit: the bot never passes region 1, so late-game pacing is not simmed; the bot does not play shops, raids or events from menus. Raw: `/mnt/project-files/sim/node-menus/sim-40.txt`.
