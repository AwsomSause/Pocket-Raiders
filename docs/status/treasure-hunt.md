- Treasure Hunt Season (idea S150; run map and world thread): a map in five pieces found over several runs. Five rare map events `th-map-1..5` (group "Treasure Hunt", `src/data/events/treasureHunt.json`) each set run flag `ev:th-piece-N`; a finished run folds the pieces into the profile (`profile.treasureHunt`, `core/treasureHunt.ts`, called from `core/profile.ts`), and every new run starts with the held pieces (`CreateRunOptions.treasureHunt`, passed from `GameSession`). With all five, the event `th-treasure` can turn up and pays once (3 items, 1500 money, 20 research); then `claimed` ends the hunt. **Save: profile v18** (`treasureHunt: { pieces, claimed }`, migration 17 to 18 with a test in `tests/unit/treasureHunt.test.ts`). Limited: no calendar "season" window (the pieces can turn up in any run); no map or HUD screen shows the pieces yet (the event text says how many you hold); pieces found in a run that is abandoned before it is finalized are not kept.
