# Shiny for every Pokémon

Done: `tools/generate-shinies.py` (`npm run shinies:check` / `npm run shinies:fill`). It scans every front and back sprite (canon and `custom/`); if the shiny file is missing, pixel-identical or nearly identical to the normal art (mean colour difference under 2/255), it writes a hue-shifted shiny (hue picked from the sprite name, so it is stable; grey sprites get colour added). Hand-made shinies are never overwritten, and sheets with a different layout are treated as hand-made. First run fixed 181 files (72 custom Pokémon incl. all Jet ones, plus some canon forms such as Minior and G-Max Corviknight). Test: `tests/unit/shinies.test.ts` (skips without Python/Pillow/numpy). New Pokémon art (e.g. from #1046): run `npm run shinies:fill` and commit the new shiny files. Limit: these are generated recolours; a hand-drawn shiny file simply replaces them.
