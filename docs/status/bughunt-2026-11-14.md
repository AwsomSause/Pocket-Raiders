# Bug hunt after Beta 0.6 (2026-11-14)

Whole-game bug investigation on `main` right after Beta 0.6 merged (#1260). Full write-up: `docs/HANDOFF.md` section 6 and `/mnt/project-files/reports/handoff-beta-0.6-0.7-2026-11-14.md`.

**Fixed (2 game bugs, 2 out-of-date browser tests):**
- **Route 22 rival fight could not start.** `cs-kanto-viridian-route22` gives the rival mark `route22-token`, which was not in `rivalOverhaul.json` `marks.names`, so "Face your rival" threw `Unknown rival mark` once the run had a registered rival (nothing happened on screen). The mark is now a known mark; a test checks every mark any event gives or asks for.
- **Evil Team leader win + a move prompt left the run stuck.** After the leader falls the Betrayal starts a wild Legendary fight (`continueEventChain`), but it never set `run.phase = 'battle'`. If a move-learning or evolution prompt came first, the run stayed on `decision` with nothing to decide: a stuck screen, and a save that reloads as "waiting on a decision that is missing". Since Beta 0.5 (#1101). Fixed, with a test.
- `tests/e2e/rescueScreen.spec.ts` predated the PS-RESCUE guard fights (Quiet Extraction always meets a guard now); it plays the fight. `tests/e2e/battleDepth.spec.ts` read the old `duo.other` shape (now `duo.slots`, #1225). Both were red on main's full CI run 2547; neither was a game bug.

**New checks (keep using them):**
- `node tools/playtest.ts <from> <count> --expansion`: the bot starts runs the way the game does, with every Beta 0.6 expansion setting on. Before this the bot (and CI) only played with them off. CI now runs 50 such runs. The bot also obeys the Pacifist Challenge.
- `tools/bughunt/fuzz-events.ts`: takes every open choice of every event in live run states and plays on.
- `tools/bughunt/fuzz-roundtrip.ts`: same seed twice = same result; a save/reload every 7 actions changes nothing.
- `tools/bughunt/old-saves.ts`: saves written by an older build load and keep playing on this one.

**Results on main + these fixes:** typecheck clean; old saves (240 Beta 0.5 runs in every phase, 38 profiles, settings) all load and play on; 616 bot runs with the 0.6 settings on had no crash, stuck run or broken number besides the two bugs above; all 3,260 events had every open choice taken in live runs (28,239 choices, 4,980 battles, 0 save-schema errors); 68 standard runs and 6 deep Extended Cut runs played twice plus once with reloads all matched; `src/core` has no Phaser import and no unseeded randomness; the new 0.6 screens (Dossier, Field Notes, Track page, Rival Report, Siege Map, Breather, Blackout, Colossus, triples at three sizes, Shadow box) showed no layout problems.

**Seen, left alone:** 11 expansion settings are stored but read by nothing (`climaxSecondShot`, `rivalOverhaul`, `rivalFriend`, `secondChancePct`, `healsPerBattle`, `revivesPerBattle`, `blessingsEnabled`, `mythicalsEnabled`, `ultraBeastsEnabled`, `wholeRunEventsPct`, `whatIfCasts`); 6 work but have no Settings row (`climaxCut`, `eventsDensity`, `kantoSevii`, `worldTracks`, `grandArcEnabled`, `minigamesDifficulty`). Pokémon moments run in single battles only.
