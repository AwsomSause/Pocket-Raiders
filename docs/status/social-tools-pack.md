- Social/tech slice 7 (S201 Leaderboard by Seed, S202 Co-op Draft, S203 Hot-Seat Versus, S204 Spectator Replay Viewer, S205 Community Content Voting, S213 Run Commentary Bot, S216 Fan Art Frame): `core/tools/{seedLeaderboard,coopDraft,hotSeat,spectator,packVoting,commentary,fanArt}.ts`, pages in Hub > Tools & Community. No save change (everything is derived from run history or kept on this device). Leaderboard ranks your runs on a seed (assisted runs never count) plus the friend ghost kept for that seed. Co-op draft: seeded pool of 14, players alternate six picks, result is a `TM1.` team code. Hot-seat: engine gets `ctx.enemyPick` (player 2's move stands in for the AI; unused otherwise, so no existing roll changes); text battle, 3 random Pokémon each at level 50, pass-the-device screen between picks. Replay viewer steps through a run's Journal with notes kept on the device. Pack voting: `PV1.<pack>.<name>` codes, one vote per friend, the leader is featured. Commentary: map line, off unless the "commentary" flag is on, chosen by hash (no gameplay RNG). Fan art frame: up to 3 images shrunk to 256 px JPEG, device only. Tests `tests/unit/socialTools.test.ts`, `tests/e2e/w12Tools.spec.ts`. Limited: hot-seat is singles, text only, no items/switching/Mega; the frame shows posters on its Tools page, not on the walkable Hub Town walls; the featured pack only moves its seeds to the top of the Seed Board.
