# New UI (the mock-ups, built into the game)

Kice's ask (2026-11-14): every mock-up in `pocket-raiders-mockups.zip`, in the game, behind **Settings > UI style** (New = default, Old = the earlier look). Update branch `ui-mockups`; notes per PR in `docs/updates/ui-mockups/`.

**How it is built.** The New UI is an HTML/CSS layer (`#rx`) laid over the Phaser canvas (`src/ui/redux/`). It uses the mock-ups' own CSS (`redux.css`) and templates (`templates.ts`, `screens/*.ts`) filled with live game data. Each Phaser scene stays the controller: it builds a plain model, calls `mountRedux(scene, { render, acts, overs })` (`stage.ts`), and the layer calls the scene's own handlers on clicks (`data-act`) and hovers (`data-over`). Keyboard input still goes through the scene. The layer never changes game state and never rolls gameplay RNG. `reduxOn()` says whether the New UI is on.

**Settings.** `uiStyle` (`new` | `old`) and `reduxSkin` (20 looks), settings v43. The address can force a style for one visit: `?ui=new` or `?ui=old`. An automated browser (Playwright) gets Old unless the address says `?ui=new`, because the older browser tests click the canvas, which the layer covers.

**Rule.** In New, a screen shows the mock-up look unless the player picked a specific style for that screen (screen style, map skin, reward skin, event style, plaza style, expedition or minigame look); that pick keeps its look. Battle: only the default look follows the mock-ups; every existing battle style stays in both New and Old (Kice, 2026-11-14).

**Done in New:** Title, Save Slots, Settings, Hub dock, list pickers (every hub room), Trainer Select, Prep Desk, Run Setup, Modifiers, Seed, Starter Select, Briefing, stage map (4 layouts, legend, banner; pseudo-stages too), Reward, Shop, Event (pages, speakers, standing panel, tournament strip and bracket, Honest Trade Card), Decisions and the Yes/No box, Trade, Expedition, Minigames, Plaza dock, timed prompt window.

**Event text as a script** (`src/ui/redux/script.ts`, tests `tests/unit/reduxScript.test.ts`). Under New, an event's `intro` and outcome `text` are read as pages:
- a blank line (`\n\n`) is a page break; each page stays until Enter or a click (Esc goes back a page);
- a newline is a new line on the same page;
- `Name: "words"` is a speaker line: the name goes on the name plate, and that person stands in the picture when the event's cast has them; any other line is narration;
- a page over about 240 letters splits by itself (between lines, then at sentence ends), so nothing is ever cut;
- the choices (and a split-second countdown, if the event has one) come with the last page; results come only after the last outcome page.
Old UI is unchanged (whole text, "Read all" button).

**Hub dock** (`HubScene`, `screens/hub.ts`). In New the Hub opens as the mock-ups' dock unless Hub style is Arena Lobby: two tabs of six buttons under a line-up of Pokémon drawn at their real heights (your walking Pokémon, your last team, past Aces, then the mock-up's own line-up). Town tab: Settings, Trainers, New Run, Events, Unlocks, Town. Last run tab: Hall of Fame, Team, Run History, Memories, Moments, Seeds. A button with several rooms opens their page; every hub room is reachable. Town > Hub Town walks the town; Esc there opens the menu, whose first row ("Hub dock") leads back. The dock remembers its tab and button.

**Board lists** (`boardView` in `templates.ts`). Quest Log, Trainer Quests, Achievement Hall and the other list rooms use one board template. A row's count ("2/5", "40%") is drawn as the mock-ups' progress bar with a state tag (New, Active, Done) and the count in words under the title (`boardProgress`).

**Party, Summary, Bag** (`screens/party.ts`, `screens/bag.ts`; controllers `ui/pokemonMenu.ts` and the Bag picker in `ui/fieldMenus.ts`). In New, Party opens as the mock-ups' page (layouts: big lead with rows, three-wide grid, list with a detail window); Enter opens the Summary: the Pokémon's card on the left, the game's seven tabs (Overview, Stats, Moves, Items, Bond, History, Traits) and the action menu as a window over the page. The Bag shows pockets as tabs, the items as a list with a detail window whose button names what Enter does (Use, Give, Change holder) or as a seven-wide grid of cells, and the party strip says who the focused item helps (Can use, No effect, Fainted, Holds it). A picked Party or Bag style still wins over the mock-up look. Grids (`gridStart`) scroll by whole rows and keep the last row on screen when the list has an uneven number of rows.

**Battle** (`BattleScene`, `screens/battle.ts`, `screens/versus.ts`). In New, the default battle look (no battle style picked) is the mock-ups' HUD: a see-through layer over the live field. The canvas keeps the arena, the Pokémon and every animation; its own boxes, text box, menus and tabs are still built (the battle's logic reads them) but left out of the picture, and each frame the scene copies what they say into a `BattleModel`. Four layouts by look: classic boxes, a full-width tray, a top VS bar, a side menu. Built from the mock-ups: data boxes (HP colours, Exp strip, status and Tera tags, the foe's team as balls), the command tray and type-coloured move buttons, the Party and Item windows (Bag pockets as tabs) and the "who to use it on" window, the info panel and a move's details as windows, the battle log with filter tabs, the transform buttons (Mega, Tera, Dynamax, Z-Move), doubles and triples with TARGET and OUT OF REACH tags, the Shadow tray, the Exp results panel, the level-up window, the evolution picture, the versus opening card for every Trainer fight (four layouts), and hover help: rest the pointer on a move for its tooltip or on a data box for that Pokémon's Ability card (after the Tooltip delay setting; Off shows none), and click a box to pin its card. A foe's Ability shows only once it has come into play. Every picked battle style is untouched in both New and Old.

**System overlays** (`ui/redux/system.ts`, `screens/overlay.ts`, `mountOverlay` in `stage.ts`). One layer over every screen, for what belongs to no screen. In New it draws the notification stack (top right; "Head: line" splits into a head and its line, the newest is bright, a tap sends one away), the achievement toast (ribbon, "Achievement", the name; a tap opens what it was for and holds it), the interaction log (L; a click or L closes it) and song captions. The canvas versions would sit under the New screens, so `ui/overlays.ts` and `ui/achievementToast.ts` hand over to the layer when New is on; Old is unchanged. **Phones:** the on-screen pad gets the mock-up's round translucent look in New and stays above the layer (`body.rx-on`), so it can be pressed over a screen. On a phone held upright the game is turned a quarter turn; the layer now turns with it (`place()` in `stage.ts`), and the turned game is centred from its layout size (`ui/portraitRotate.ts`; before, it sat off to one side and was cut off, in Old too). The mock-up's "turn your phone sideways" notice is not built: the game turns itself instead.

**Hover help outside battle** (`ui/redux/tips.ts`). `hoverTips` gives any view the Tooltip delay (`tip` option of `mountRedux`, `data-tip` on the element). The map: rest the pointer on a party Pokémon in the header for its Ability card (the mock-ups' Pokémon info card). The Summary's Overview: rest on a move chip for the move tooltip. The battle uses the same builders (`ownAbilityCard`, `moveTipOf`). **Bonds** (`ui/bondMenu.ts`): the mock-ups' board, one row per Pokémon with its Trust bar ("Max" at 100) and trait, mood and role under the name; the other six values are read out in the text box with the usual notes. A one-column board shows one row fewer while its text box is three lines or longer, so no row hides under it.

**Run end** (`GameOverScene`, `screens/over.ts`, `screens/cut.ts`). In New (unless a Run-end style is picked) the run ends on the mock-ups' `over` page: title, a facts window, a Payouts window, the last party and three buttons (Witness the rest or Roll credits, Run card, Back to Hub). Witness the Rest plays the rival letter and `witnessCards` as cutscene cards (`cutView`, the mock-ups' `cut` template in three layouts; it is the base for the other cutscenes). The run card is the mock-ups' `card` page (Enter saves the PNG). Tab opens the full report (`reportPages`: every line of the Old screen, paged), F the final team (the Party page with a gold header), R retries the seed. The Old screen is still built underneath and keeps its keys (G, T, C, S).

**Event extras.** `EventView.standing` (rank and up to three meters) draws a standing panel. A trade that names what comes back (`TradePick.gets`, from `tradeFor.table`) shows the Honest Trade Card: both sides before the player commits; "Not known yet" when the event does not say. A long choice label shrinks and wraps inside its button. A hover only counts when the pointer moved, so a resting mouse never steals the keyboard cursor.

**Tests.** `tests/e2e/newUi.spec.ts` (New: title to map, an event by clicks, paged event text, a tournament with its bracket, a pseudo-stage's rooms, the Hub dock and the way to Hub Town and back, a decision with the confirm box, Party to Summary to the action menu, the Bag with a Potion used from its window, a lost run's end page with Witness the Rest, report, final team and run card, the style override; the battle: boxes and a move by click, the Party and Item windows, the versus card, a win's Exp panel with the level-up window and the evolution picture, the hover tooltips and a pinned card; the system overlays; a phone held upright and sideways; the map's info card, Bonds and the Summary's move tooltip; the map's Rival Report, Notebook, Dossier and Field Notes; Galar's bracket with a watched match). Unit: `reduxPopups`, `reduxOverlay`, `reduxScript`, `reduxEventView`, `reduxBracket`, `reduxBoard`, `reduxParty`, `reduxBag`, `reduxOver`, `reduxBattle`, `reduxVersus`, `tradeCard`. All older specs run under Old.

**Clicks stay on the layer** (`shield` in `stage.ts`). Phaser also listens on the window for presses outside its canvas, so a click on a New window used to press the old canvas button hidden under it as well (the log window over the title chose a title entry). Every New stage and the overlay now keep a press that began on them (mouse and touch) away from the canvas; a drag that began on the canvas still ends wherever it is released.

**Map pop-ups.** In New, R (Rival Report), T (Notebook track page), D (Dossier), F (Field Notes) and B (Galar's bracket) draw as the mock-up pages (`src/ui/redux/screens/popups.ts`, pure; `bracket.ts` `galarPage`), in both layouts each. MapScene keeps one `rxPop` state and builds the models from the same core views the canvas pop-ups read (`rivalReport`, `trackPage`, `dossierFolders`, `fieldNotesView`, `bracketTree`). The same key closes; Esc or Enter closes too; arrows change folder, tab, page, person or rival; rows, tabs and chips can be clicked. The key that opens a pop-up can also be a direction (D is "right"): that press is ignored as a direction. Galar's bracket is the mock-up tree in five pages (four groups and the finals) from `bracketTree` (core, read only, no RNG stream of its own); the text box carries the next opponent, field strength and the big-screen line; W or its chip replays a match (canvas, the layer steps aside). Limits: the Dossier's "Met" row is the stop number (the mock-up names a place); Rival Report facts are role, style and battles (the game does not track a rival's team size or lead Pokémon on the map); Feelings shows the four strongest of six; in the book layout Field Notes shortens the tab names so all four fit down the edge.

**Important moments** (`ui/redux/moment.ts`, `screens/cut.ts`). In New, a battle's big moments play as the mock-ups' cutscene card (plate, name, one line, the picture, the five-beat strip) instead of the canvas cards: Gym Leader, Elite Four and Champion intros (before the versus card; they replace the canvas boss entrance), the ace's entrance, the Champion's Final Battle, Evil Team reveal and the Betrayal, raid intro and defeat, boss defeat (with the boss's own last line), rival first meeting / rematch / revenge / reunion, the Ultimate Rival's "Final Rival Battle", the Galar stadium cut-ins and round openings (`StadiumHooks.card`), mentor assist, graduation and protégé return, a wild Legendary or Mythical reveal, the player's first Mega Evolution of a run, and the Hall of Fame card after a Champion falls. `playCutMoment` follows the moment's plan from `core/cinematic/moments.ts`: the five phases are the five beats; a spoken line adds reading time to the middle beat; with animations off the card shows once; a skippable moment ends on a click, Esc or a held Space, and a skipped boss intro is remembered as before. The Pokémon cards show the player's back view when their Trainer has one, else their usual picture. Presentation only: nothing here reads or changes battle state. Tests: `tests/unit/reduxMoment.test.ts`, and the Gym Leader / Legendary test in `newUi.spec.ts`.

**Opening screens** (`screens/boot.ts`, `screens/prologue.ts`). Loading and the update splash are the mock-ups' `boot` page (`BootScene` mounts it unless a loading look is picked; a click on the splash skips it). The welcome log and the tutorial (`TutorialScene.ts`, both `PagedScene`) and the prologue's talk steps render through the event talk page (`money: null` hides the coin tag); the prologue's opening shots and Departure pages are cutscene cards; the name and custom-pronoun steps are the mock-ups' `form` (`formView`, on-screen keys, raw keyboard typing through `typeKey`). `PrologueScene` stays the controller: its layout helpers write what a step shows into `rxM` and `rxRender` draws it. Vance and the player are drawn from one frame of their sheets at the mock-ups' exact scale (`big()` in `rxRender`: 0.9 and 0.8 of the page's figure scale; on a card the rows under the card's edge are cropped off). Credits are the mock-ups' `credits` page (`CreditsScene.createRx`; the roll is moved in `update`, 1000/28 px a second as the Old roll). A talk page with a long choice list (the ten tutorial choices) shortens its buttons, uses two columns or one-line cards by layout. Limits: the form's last four keys are - ' space delete (mock-up: 0 to 3); a card that cannot be skipped shows "Enter next"; four tutorial professors have no art.

**Story scenes, Rescue, Siege, Field Trial card** (`screens/ops.ts`). `StoryScene` renders through the event talk page (tag "kicker n/of", the player portrait from `playerPortrait`). `RescueScene` keeps the rules and feeds `rescueView` one "card" per step (offer, beat, complication, guard, exchange, result): lines are paged one speaker to a page (`pageLines`, 150 letters), choices come with the last page, and a choice may carry what the box says while the cursor is on it (a plan's pitch or lock reason). The receipt is read from the hold (`readSlip`) and the stamp is the hold's clock state; the result stamps HOME / SOME HOME / STILL HELD. `SiegeScene` feeds `siegeMapView` (ledger grid in layout 0, rows in layout 1); a district click only moves the cursor, the button calls `chooseOption`. `FieldTrialScene` mounts the battle's `versusView` first (rival picture from the Story character's pose via `characterArt`). `mountRedux({ card: true })` marks a full-screen card: the overlay hides notices and toasts while one is up (`reduxCardUp`). `portrait()` / `playerPortrait()` in `templates.ts` hold the mock-ups' portrait scale. Tests: `tests/unit/reduxOps.test.ts`, four tests in `tests/e2e/newUi.spec.ts`.

**Wide formats** (`screens/wide.ts`, `wideModel.ts`). `FormatScene` in New mounts `wideView`; `widePage(scene, ctx, index)` reads the running format's state and card (core/formats) at every draw and returns the model plus the option ids and which are open. Bodies: breather (party strip with notes, "Bring one back", "The quiet room"), blackout (a card per anchor, the Seal with `Anchors fallen n / SEAL_BREAKS_AT`; the card's own "Anchors beaten" sentence is dropped), convoy (road and trucks), front (lanes, once fought), debate (opponent, score dots, claim, arguments tagged Evidence/Reasoning), plate (Colossus: Apex picture and Blueprint rows), plain (anything else). The scene keeps only the cursor; `chooseOption` and the save are the same calls as Old. Tests: `tests/unit/reduxWide.test.ts`, three tests in `tests/e2e/newUi.spec.ts` (Breather, Blackout, Colossus).

**Town Roll and League counter-pick.** `core/expansion/townRoll.ts` `townRollPages(content, run)` reads the stored canon menu of the stage's slot (and its interlude) and returns cards: on the map first (always / rolled / unlocked), then the optional ones left out; it never rolls (spaces with no event or raid are left off, as on the map). `MapScene` adds a `roll` pop-up (key O, shown in the header keys when a page exists) drawn by `rollView` in `screens/popups.ts`: up to four cards in the mock-up's row, more than four keeps cards for placed spaces and lists the rest as tags. `DecisionScene.buildLeagueDoor` (New only) mounts `counterView` (`screens/ops.ts`): the cursor walks the box rows, then the swap and keep buttons; Enter on a row marks it and jumps to the swap button; the answer is the same `circuit` choice as Old (0 keep, n swap). Tests: `tests/unit/townRoll.test.ts`, `reduxPopups` (Town Roll), `reduxOps` (League counter-pick), two tests in `tests/e2e/newUi.spec.ts`.

**Known limits.** Moments: the game has no species category ("Sky High Pokémon"), so a Legendary's plate is its event epithet or "Legendary Pokémon" and its line is the same for all; "first Mega" is the first in this sitting of a run (it shows again after a reload); the Hall of Fame card plays after every Champion win. Still Old-drawn inside New: the pause menu (the game has none; the map's menu is the nearest), the transformation scenes (Mega, Z-Move, Dynamax, Tera), the map's node menu and the tournament's match replay, the Field Trial's spar (its opening card is New), egg hatch, Legendary title cards, and Pocket Town (the mock-up shows it as a dock; it is still the walked town). The Plaza in New is the dock (walkable plaza: Old or another plaza style). The New UI ignores Font size and Dyslexia font. Trade shows type chips instead of the mock-up's HP bar. There is no mock-up for walking Hub Town, so it keeps its own look (Hub dock > Town > Hub Town).

**Battle limits.** While the Item or Party window is open, the text box says what the focused row does (the mock-up keeps the command menu there). The evolution picture has no "B stop" hint: the game has no way to cancel an evolution. The versus card shows the foe's first Pokémon as a picture and the rest as balls, so the team stays hidden; the foe's quote is the same opening line the battle then says. The Ability card's "Seen in" counts earlier runs (the Pokédex research tally), not this run.

**Fonts.** `public/assets/fonts/redux/` holds the nine font files the mock-ups use (Cinzel, Jersey 15, M PLUS Rounded 1c, Oswald, Pixelify Sans, Rajdhani, Tiny5), taken from the mock-up pack; all are Google Fonts families under the SIL Open Font License 1.1.
