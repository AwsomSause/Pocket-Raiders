- **Beta 4.4 bug list, part 4 (screens and moves)**: Devon Scope (and Town Map) previews walk to the node on a copy exactly as choosing it does (`run.ts mapPreviews` uses `moveToNode`), so a tick of the clock no longer shows the wrong wild Pokémon. The catch screen shows the nature and what it changes (`catchSummary.ts`). Moves: Confusion, Psybeam, Water Pulse confuse; Supercell Slam crashes on a miss; Mighty Cleave and Feint go through Protect; Zippy Zap raises evasion (moves.json). Every ordinary move has its in-game description (`src/data/moveDescriptions.json`, from PokeAPI's flavor text via `npm run data:move-text`), shown with this game's numbers in the battle move info and on the learn/teach-move screens (`moveText.ts moveFullDescription`). Skip guard (setting, on by default; settings v33): a held confirm/back key never races through text, a press in the first 250 ms of a new screen is ignored, and a confirm pressed during a screen change is no longer replayed into the next screen (`ui/input.ts guarded`). Tests: beta44Moves, skipGuard, catchSummary, mapMoveItems. Limits: Modifier Run and the modifiers page work in tests and the browser (mutators picked every 5 battles); menu creation measured at 16-190 ms headless, so the reported slowness is not reproduced yet.
