- **Species research (S497, 2026-11-06):** each species has research levels from two tasks (meet it 1/3/8/20 times, catch it 1/3/6/12 times; `src/data/dexResearch.json`, `core/dexResearch.ts`), up to level 8. A run counts every meeting and catch in `run.log.dexTally` (via `discover`); when the run ends `applyRunToProfile` adds them to `profile.dexResearch` and pays 1 Research Point per new level, plus a 10-point Perfect bonus the first time a species reaches level 8. The Pokédex page and browser show "Research level N of 8 · Next: ...". Both new fields are optional with defaults, so old saves load unchanged (no version bump; tested).
