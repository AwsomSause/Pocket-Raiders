# S6i: Snacks and Heartbond

- Feeding the partner a **loved** snack pays affection +2 (the usual +1 care touch plus 1). A **neutral** snack pays +1. A **hated** snack pays 0 Heartbond and never costs any (the sulk stays as before). Still capped at 3 care touches per stop, shared with every other care action.
- No save bump; Classic runs untouched.
- Talk, Play, Pet already exist as care actions and already pay (S6c). Embrace is the existing Hug. Still open in S6: a level 7 gate for Embrace, keepsakes, override cost, Autonomy Off, Keystone Memory.
