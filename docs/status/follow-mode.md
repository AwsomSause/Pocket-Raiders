- **Follow mode (S501, 2026-11-06):** a free camp action `follow` (`run.camp.follow`, default off, no save version change) lets the lead Pokémon walk beside you. While on, every stop the first standing Pokémon gains `balance.friendship.perStep` friendship and has a `findChance` (10%) to dig up a potion, Poké Ball or Super Potion (`followFinds`); the line shows with the other stop notes. Seeded per stop (`core/followMode.ts`, stream `follow`), so old seeds are unchanged while it is off. Tests `tests/unit/followMode.test.ts`. Limited: no overworld sprite following the player on the map; the finds are items only.
