# W2: Unconventional aces and rival adaptation

Story Overhaul design 14.5 to 14.7. No save bump (all new fields optional).

**What the player sees**: a returning rival now reacts to *how* you played against it, not just your move types, and says so before the fight ("{rival} watched you stack boosts. This time Pidgeot is ready."). Its ace grows along a fixed ladder (one new move or item per phase), and later aces can carry one surprising coverage move.

- **Coverage budget (14.5)**: `src/data/rivalCoverage.json` (20 sets), `core/rivals/coverage.ts`, numbers in `balance.rivalCoverage`. Rules checked: ace max by phase (1/2/2/2), team max 3 (4 champion), both top weaknesses never covered, 2+ open weaknesses, no Focus Sash with a 4+ type move, listed answers/open weaknesses must match the type chart. Phase gate: a set answers a type only after the rival saw it in 3 battles; `unexpected_coverage` sets never answer your top type, are the one unannounced surprise, and skip a meeting where the rival adapted. Desperation needs 2+ setbacks.
- **Ace ladders (14.6)**: `src/data/rivalAces.json`, `core/rivals/aces.ts`. 17 rivals x 4 phases. A rival with a ladder takes that line as its ace (`ensureAce`); levels never change. Phase = region (early 1-2, mid 3-5, late 6-9, champion 10+).
- **14 triggers (14.7)**: `src/data/rivalAdaptations.json`, `core/rivals/adaptTriggers.ts`. After a rival battle the rival records what it saw in `rival.seen` (setup, priority, switches, status, recovery, weather, hazards, pivots, gimmick, lead, sweep, legend). Per meeting max 1 hard + 1 soft counter; new triggers use the rival's existing adaptation cap; 1x triggers fire once (story flags `rival-adapt:<rival>:<trigger>`). #6 is the existing resist swap.
- Engine: `playerMovesSeen` now counts status moves too; new optional `battle.playerSwitches`; knockout events carry `turn`.

**Changed from the design data**: sets whose design move broke the budget or can't be learned here were swapped: Swellow Heat Wave (no Icy Wind), Typhlosion Thunder Punch, Arcanine Thunder Fang, Gyarados Ice Fang, Garchomp Fire Fang, Feraligatr Dragon Claw, and Scizor (only one weakness, can never pass) replaced by Excadrill Rock Slide.

**Limits**
- Gimmick ladder steps (Mega Pidgeot, Mega Gardevoir, Bede) only give the stone when it exists; rival Mega Evolution is not built (needs `transform.ts bossMechanics`). Mega stones and Heavy-Duty Boots are not in the item list, so those steps/counters fall back (boots -> Rapid Spin/Defog).
- N, Gladion, Kieran steps that need Illusion tricks, Memories or rematch rules are "none" steps. Story rivals (Dara to Marisol) wait for Story Run; Marisol's Bastion is not in.
- Status "landed" counts status moves used. A "sweep" is one Pokémon knocking out 3+ in a row, each within 2 turns. Only `fought` sightings (no `witnessed`/`public` yet).
- Coverage and triggers run for the returning-rival path (`run.ts`), not the Gym takeover path.

**Sim**: `node tools/overhaul-sim.ts 30`: the bot beats early rivals 76 of 82 times (93%, before W2 about 89%); these bot runs end before mid-phase rivals, so mid/late adaptation is covered by unit tests only.

**Tests**: `tests/unit/rivalAdaptW2.test.ts` (budget over all 20 sets, ladder rows, triggers, caps, determinism); `rivals.test.ts` checks a real battle records the lead.
