- Mining Spots (S231), capture slice 5 (`core/mining.ts`, `data/mining.json`, `services.json` `mining`): a new one-use map stop with two digs. Shallow is free (small gems, now and then a stone); deep costs ₽300 and can turn up fossils, rarer stones and gem hoards. One seeded roll per dig (own generator: run seed, stop, dig), so reloading the stop gives the same find; no save change. Test `tests/unit/mining.test.ts`. Limits: finds are a fixed table, not tied to the stage's theme; fossils are the Kanto/Hoenn/Sinnoh/Unova sets in `itemCatalog.json` (Hisuian fossils not in the table yet).
