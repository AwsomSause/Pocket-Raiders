- Endless Tower (idea S14; run map and world thread): new mode `endless-tower` in `runRules.json` (practice: `progressionEligible` false). Like Endless but with no lap limit; every new lap adds +4 enemy levels and a seeded level curse from `mutators.json` (Tough Foes or Hard Hitters, +2/+3 levels, bigger end-reward bonus), picked by `hashSeed(seed::tower::lap)` in `extendEndless` (`core/rules.ts`, new mode field `loopCurse`). Curses are stored in `run.mutators`, so saves load as before: no save version change, no new field. Tests in `tests/unit/rules.test.ts` ("Endless Tower"). Limited: the tower is the existing region laps, not a separate floor map; no tower-specific rewards or leaderboard yet (it is a practice mode); curses repeat after a few laps and stack.
