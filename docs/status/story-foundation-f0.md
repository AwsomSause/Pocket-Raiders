# Story Overhaul F0: save and data foundation

- Saves bumped once for the whole Story Overhaul: **profile v20, run v40, settings v39**. All three are additive. `profile.story` (Look, name, prologue, Remembrance, lore, cast, chronicles, endings) and `settings.story` (9 settings) get defaults; `run.story.v2` is optional and only Story Runs will set it. Later slices add fields **inside** these containers and must not bump again. Profile v20 also turns every `npcMemory.lore` id into `story.lore[id] = known` (npcMemory itself is untouched). A damaged `profile.story` falls back to defaults (Zod `.catch`) and the rest of the profile loads.
- Data: `src/data/story/*.json` (13 empty files plus `text/en.json` and `hash.json`), schemas in `src/core/story2/schema.ts`, loaded into `content.storyData`. `npm run data:story` validates and rewrites `hash.json` (`--check` only verifies). `report:check` fails if the hash is stale.
- 19 gates in `src/quality/storyGates.ts`, shown in `npm run report:check`; baselines are 0 in `tools/content-baseline.json`. `tests/unit/storyGates.test.ts` seeds one bad record per gate. Quiz-balance reads the design doc as: each trait totals 18 +/- 1 over all answers, and each question's heaviest answer is 14 +/- 1; the quiz slice may refine it.
- Helpers: `sanitizeName` (grapheme count, bidi/zero-width/markup rejected), `romanceEnabled` (false while `settings.story.romance` is off or the balance flag is off).
- Checked unknowns: `run.campaignId` is a plain `z.string()` (so a new campaign id needs no bump). Profile, run and settings Zod objects are not `.strict()` (extra keys are stripped, not rejected). Corrupt profile/run saves are copied to `pkr.<record>.corrupt.<time>` before a fresh one is made; there are no rolling version backups, so none was added. Evil-team beats come from evil data `config.beatEvery`/`firstStage` (no hard stage cap); the stage-list slices (S1/S4) must re-check the beat schedule against 26 map stages.
- Not in F0 (later slices): bus subscribers on `emit`, settings screen, Character Select lock, `orrery-circuit` campaign entry, Hub rooms, pronoun rendering, `story.enabled` flag.
- Tests: `tests/unit/storyFoundation.test.ts` (migrations, round trips, size budget, bad story object, failed migration, loader, name fuzz).
