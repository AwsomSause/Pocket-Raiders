- Wandering Merchant Line (idea S144; run map and world thread): a 4-visit merchant route in `src/data/events/wanderingMerchant.json` (group "Wandering Merchant"). `wm-1` is an ordinary uncommon merchant stop that promises to be back; each later visit (`wm-2` to `wm-4`) is a `callback` event that gets a forced stop on the next stage, gated by run flag `ev:wm-route` (1, 2, 3), with better stock each time and a free gift at the last stop. Buying or waving goodbye moves the route on. No save change. Test `tests/unit/wanderingMerchant.test.ts`. Limited: the route is by stage (always the next stage), the column is random; skipping a visit by never finishing its event ends the route.
