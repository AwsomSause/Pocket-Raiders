- Raids & bosses slice 5 (`s-raids-bosses`): **S404 Raid Medals**. A raid now records damage dealt to the boss and HP mended by Supports per Pokémon (`raid.damageBy`, `raid.healedBy`, optional with defaults, no version bump). A won raid hands out two more raid memories beside the existing five: "Hit the Hardest" (most damage) and "Kept the Team Going" (most mending, only if someone mended), each with the usual friendship share. Practice fights award nothing. Tests `tests/unit/raidMedals.test.ts`. Limited: no medal screen; healing from items is not counted.
