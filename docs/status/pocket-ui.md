# Pocket look (the Pokémon-style UI redesign, built for real)

Kice, 2026-11-20: "All of the most recent ones look fine. Build into the game now alongside the animations in the animations thread. Prioritize the looks of the UI thread (Current) while prioritizing the animations of the animations thread. IF A MENU OR ADDITION DOESNT ALREADY EXIST IN GAME, ADD IT" and "BUILD EVERYTHING AS CLOSE TO THE MOCKUPS AS YOU CAN". The mock-ups are in `plans/ui-redesign/` (283 pages; status in `docs/status/ui-redesign-25-passes.md`).

## What it is

A fourth UI style next to New, Phantom and Old: **Settings > Display > UI style > Pocket**. New stays the default until every page is built; then Pocket becomes the default (Kice's choice, 2026-11-20). No save version changed: `pocket` is one more value of the `uiStyle` setting.

Kice's picks decide which pass a page is drawn at: Title pass 17, Pause menu pass 24, the main game the Final Cut (slider 26), the new areas the Master Cut (slider 51). Dominion / Evil Mode pages are left out.

## How it is built

- It uses the New UI's HTML layer and the same scenes: a scene still owns the state and the keys, and its view draws a Pocket page when `ReduxCtx.pk` is set (`src/ui/redux/stage.ts`). A view's HTML that starts with the Pocket mark (`<!--pk:<page>:<tier>-->`) is drawn on its own layer `#pkx`, a 960 x 540 stage scaled to the window.
- The rules are the mock-ups' own CSS: `node tools/build-pocket-css.mjs` turns `plans/ui-redesign/src/pNN.css` into `src/ui/pocket/pocket.gen.css` in four tiers (17, 24, 26, 51), animations renamed `pk-...`, pictures as CSS variables. Hand additions go in `src/ui/pocket/pocket.css`; their classes start with `gx-`.
- Pages are in `src/ui/pocket/screens/` and `src/ui/pocket/templates.ts`, built with `src/ui/pocket/kit.ts`. Each page is ported from the mock-up's final HTML (`node tools/pocket/dump-pages.cjs <dir>` writes all of them), with the same class names, so the mock-up's rules apply as they are.
- Sprites are drawn as the mock-ups draw them: the first frame, cut down to the drawing, as an `<img>` (`src/ui/pocket/art.ts`).
- A page change is the browser's view transition, as in the mock-ups (`src/ui/pocket/turn.ts`); with menu animations off, pages simply change.
- A screen that has no Pocket page yet shows its New page, so the whole game is playable in the style from the first part.
- `?ui=pocket` in the address forces the style for one page load (the browser tests use it).
- Motion inside battles, the stage map and the Blessing screen belongs to the animations thread (`docs/status/animation-redesign-25-passes.md`); this look gives them the cards to move.

## Known limits

- Parts 1 to 4 and the Hub street only: Pocket Town, new areas and the rest still show their New page in the Pocket style.
- Hub street: the mock-up's doors (Achievements, Poké Mart, Gallery) are the game's own dock buttons (Unlocks, Town and the Last run tab); the buildings stand for Events, Trainers, New Run, Unlocks and Town. The Rotom line, rivals and sky the mock-up hides are left out too.
- Pocket Town: the street is still the walkable canvas town (the mock-up's flat row of buildings is a picture of it). Esc opens the town menu (the mock-up says "back to the Hub"; Back to the Hub is in that menu). The Town Map walks you to a district's first door; the Phantom directory's visit-from-the-list stays Phantom only.
- Run start: the Briefing's map is the Kanto Town Map for Kanto and the plain island map for every other region (the packs have no other region maps). The Starter Pick has no Summary key (the game has no summary there yet).
- Memories: the inner pages (Run Journal and the rest) still use the shared Pocket list; while a revisited timeline is in play the Legacy Gallery keeps the list so its Continue and Abandon rows show.
- Preparation Desk: the Seed page has Random, Type one and Paste (the mock-up's Daily is a mode on Run Setup, not a seed); the Trainer page draws a Poké Ball for a chosen Preparation, Directive, License, Loan or Mentor (the packs have no art for them).
- Trainers: all 287 Trainers stand in the row (the mock-up shows the five player Trainers); Tab still sorts and R still flips, and the grid's paging is gone in this look.
- Blessing: the mock-up offers three blessings to pick from; the game deals one per run (from the shuffled bag), so the page shows that one card. Choosing among three would change the rules and is not done.
- Credits: the mock-up walks the Trainer at the end of the team; the game has no walking sheet for every Trainer, so only the Pokémon walk. The mock-up's "Next stop" loading card and Run Report page are new pages, left for part 7.
- Badge Case: the game picks each Gym Leader when its stage begins, so later Gyms show as "not met yet" (the mock-up names all eight). The region page shows once per visit; coming back to the map from a menu shows the short sign instead.
- After a battle: the Victory page shows for a beaten Trainer only (a wild win goes straight to Team EXP, so the many wild battles take one page, not two). Its rows are the game's own (no "Nobody fainted +₽200" bonus: the game has none); the stars are 3 with nobody fainted, 2 with less than half, 1 otherwise. Learn it still asks the game's "will forget… OK?" question.
- Stage map legend: a run that meets every route obstacle lists 46 rows; the legend then uses five narrow columns and puts the stage notes in two columns, so nothing is cut off.
- Badge get and rival loss: the mock-ups' second buttons (Badge Case, Rival Board) are left out: those pages open from the map, not from a battle. The game has no badge names, so the badge is "Misty's Badge".

- Rival Board: the game does not know where a rival will turn up next, so the third row is the lead; Enter opens the full report (still the New look's page), not "their team so far".
- Legendary cut-in: the shine spiral is drawn with CSS (the mock-up's shine picture is not in the game's art). The boss panel sits under the stage strip (the mock-up has no strip) and names the badge by its type.

- Battle Log: the game keeps the battle's lines, not who did what each turn, so the log is one list under the current turn (the mock-up groups it by turn with damage totals). The move card leaves out the mock-up's "Takes about 18%" bar: the game has no damage preview that uses no dice.
