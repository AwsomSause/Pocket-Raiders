# Story Overhaul S5: backstory module loader and Viridian vertical slice

- **Loader** (`core/story2/module.ts`, state in `run.story.v2.module`, no save bump): a Story Run gets one enabled backstory (`balance.story.module.enabledBackstories`, only `bs_viridian` for now; S2 will let the player choose, until then the seed picks), its hidden flags are rolled once on a `story_module` seeded stream (`rolls`; Viridian: `rapport_nature` practiced 70 / resonant 30), its reception modifiers apply once, and the intro is queued. Scenes play on Story Stops (`playStop` calls `queueStopScene`): follow-ups and the intro first, then the slot's own event if it belongs to the module, then the next manifest event (act tags, requires, arc steps in order), echoes from Act 4 (`echoFromAct`), the ending at the Epilogue. `gapStops` keeps one empty Stop between scenes; evil beats, hideout, leader scenes, Region Gates and the Finale are never played over.
- **Effects** (`applyEffects`): set_flag, add_counter, add_relationship (named characters go through the S8 cast records; `class_*` targets are kept as `rel.class_*` facts), unlock, unlock_lore, give_item, add_memory, chronicle. Each effect id applies once (`v2.fired`). Flags and counters live in `v2.facts`.
- **Screen** (`scenes/StoryScene.ts`): Enter turns pages, the last page of a choice scene lists the answers (up/down/Enter). MapScene shows it before the map or the next battle; GameOver shows the ending first. The choice is applied by core, not by the screen.
- **Ending**: the Epilogue Stop picks the row of the module's `endingGrid` (first match) and commits it at once (so a run finalized before the screen is read still keeps it). Chronicle gets `ending` (optional field) and an "Ending:" line.
- **Profile at run end** (`foldModuleIntoProfile`, once per run): Remembrances unlocked, Lore learned, `endingsSeen`, and up to 60 scene snapshots in `profile.story.sceneSnapshots` (`{event, stop, act, text, choice, runId, backstory}`) for the Story Journal and Archive screens. Arc progress is in `v2.arcs`.
- **Data fixes to S1's Viridian grid** (needed so all four endings can be reached; the old thresholds were unreachable, max Rapport in the module is 7): grid order is now Echo, Gardener, Listener, Reckoning with Gardener at Rapport 5, Echo at 6 (and resonant), Listener at 3; The Hush needs Rapport 5 (was 9).
- **Limits**: only 3 echo events are authored (plan said 5); `item_*` rewards, encounter pools and `prop_leaf_satchel` are named flags, not built; the Nidoran Remembrance is still missing (id pattern); `class_*` relationship shifts are stored, not yet applied to the characters that fill those roles; a lost run that never reaches the Epilogue has no ending; an old in-flight Story Run gets a module (and the intro) the next time `ensureStoryRun` runs.
- Tests: `tests/unit/storyModule.test.ts` (8: start and Classic untouched, determinism and validator, whole slice, 100-seed fuzz, all four endings reachable, effect applied once, reload, profile fold), `tests/e2e/storyBackstory.spec.ts`, `storyCircuit.spec.ts` updated for the intro scene.
