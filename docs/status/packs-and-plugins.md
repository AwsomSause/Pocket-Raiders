Atlas builder: `python3 tools/build-atlas.py <folder> <out>` packs PNGs into one atlas plus Phaser JSON (deterministic). S337 already existed (`ui/lazyAssets.ts`: Pokémon files load on demand). Tests `tests/unit/packsAndPlugins.test.ts`.
