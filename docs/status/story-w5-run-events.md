# W5: Run event infrastructure

- **Tags** (`EventDef.tags`, 16 values; empty = defaults by `group`), **priority** (`events/priority.ts`: common 10, uncommon 30, rare 50, Legendary/epic 60, forced 70 to 100; ties hashed on seed + id), `forced` (Critical: never random) and `disabled` fields on events.
- **Queue** (`story.eventQueue`, optional, max 4, no save bump): `addEventStops` gives forced events a stop (2 per stage), the rest wait. After 2 stages a Critical event becomes a first stop with no cap; others expire with a journal line ("A chance passed: ..."). Entries that stop being eligible expire. An id is placed once (the existing `event-seen:` counter) and never twice in one stage. Legendary-rank events: max 1 per region and 3 per run (`epic-seen:<region>` counters).
- **New conditions**: `rep` (reputation level) and `badges`.
- **25 catalogue events** (`src/data/events/run-catalogue.json`, auto-loaded). **12 play now**: Rival Sighted, Unexpected Challenge, Rival Rematch, A Lost Pokémon, Pokémon Migration, Ancient Discovery, Regional Festival, Pokémon Sanctuary, Elite Four Exhibition, Champion's Challenge, Abandoned Expedition and Hidden Dungeon (W6). **13 are `disabled`** until what they need exists: dungeons (W6: Forgotten Research Lab, Treasure Expedition), pseudo stages (W7: Champion's Invitation, Distortion Rift, Lost Civilization, Dimensional Collision, Trainer Tournament bracket), world layer (W8: Legendary Disturbance), rival milestones (W4: Rival's Victory, Rival's Defeat, Rival Emergency), recurring-trainer ladder (Trainer Reunion), live evil ambush covers Evil Team Raid. Disabled events are never drawn or queued.
- Limits: no catalogue event is `forced` yet (none of the 25 is Critical in the design). The queue is used by the first forced events of the S track. Pokémon Migration and Sanctuary are wild-battle versions (the stage wild table is not changed). The two exhibition fights are normal fights (they use the E4 boss Lorelei and the Champion Lance), the design's "no loss cost" rule is not applied.
- Tests: `tests/unit/runEvents.test.ts`.
