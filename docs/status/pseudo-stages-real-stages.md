- **Pseudo-stages are real, drawn stages inside one node (Beta 0.7, Kice 2026-11-15).** A pseudo-stage plays like a stage (full node map on the normal map screen, the stage's own background art and theme), but it lives inside ONE node of the parent stage, is always opened by an event, and never adds to the node count, stage index, badges or region progress. Entering swaps `run.stage` for the pseudo map and keeps the real stage in `run.pseudoParent`; the exit room (or a lost fight) swaps it back and you stand on the node you came from. No save version bump (new fields are optional); a save made inside an old room chain keeps working because the room event ids are unchanged.
- **The 10 stages** (`src/data/pseudoStages.json`, `src/core/dungeon/pseudo.ts`): Safari Zone, Battle Frontier, League Exhibition, Distortion Incident, Evil Hideout (no longer counts as a stage), Dreamscape, Distortion World, Ancient Wilds, Celestial Expanse, Lost Island. Each record has a `themeId` (background art). The map is the record's room graph (one column per step); the player picks the route, reaching a node opens that room's event (wild, rare, trainer, boss, puzzle, trap, chest, rest and so on), the exit room pays the reward and walks out. Rooms no longer open each other; new effects `enterPseudo` and `leavePseudo`.
- **The Kanto lines as pseudo-stages** (`chains` in the same file): Flight North, Sabrina's Labyrinth, Route 25 and the Fighting Tournament. Their maps are drawn from the events' own `addEvent` links, so every room, line of text, fight and rule is unchanged. The first room(s) are picked on the map; after that each room opens the next and walks the player along the map; the last room walks back out. Route 25 handing over to the Tournament leaves the stage first, so the Tournament opens on the parent node as before. Poli-Pond and Pidgey's Resolve are not pseudo-stages in Kice's spec and are untouched.
- Limits: the 10 maps are short (3 to 7 columns, as authored); chain maps are not clicked node by node (the story's own choices decide the route); no stage forecast or weather fronts inside; no mid-stage "Leave" (rule P2 still offers Leave at the gate).
