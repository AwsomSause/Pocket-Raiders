- Migration Seasons (idea S135; run map and world thread): `migrationWildWeight` in `core/clock.ts`, data in `balance.json` `clock.migration`. Each run-calendar season brings some types through (Spring flying/bug/grass, Summer fire/water/electric, Autumn normal/ghost/fighting, Winter ice/steel/dark): wild Pokémon of those types are drawn 2x as often, and half as often in the opposite season. Read from the run clock only (no saved state, no gameplay RNG), applied beside the time-of-day and tide weights in `core/run.ts`. No save change. Test `tests/unit/migrationSeasons.test.ts`. Limited: the weights are a nudge on the stage's own pool (a species that is not in the region's pool never appears); no UI line yet says which types are passing through.
