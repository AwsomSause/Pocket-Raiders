# Story Overhaul S11: themes

- **Four theme cards** in `src/data/story/themes.json`: Shadows of Viridian (`th_shadows_viridian`), The Rival's Promise (`th_rivals_promise`), A Champion's Legacy (`th_champions_legacy`) and **The Mythic Equation** (`th_marauder_conspiracy`, Theme J). Each has a 9-section beat sheet (Prologue, Acts 1 to 6, Finale, Epilogue; Mythic uses the 44-Stop plan), 10 exclusive events (`theme_<id>` tag, pinned to a named beat by a slot rule), 2 twist cards with 3 or 4 clues each planted before the reveal, a Journal tab with 3 templates, a backstory fit table, and an ending table (first match wins, catch-all last: 5 endings per card, 7 for the Mythic Equation).
- **Theme O (The Quiet Between Storms) is not built**: Kice parked it (Appendix S).
- **Ending flags**: event choices set the story flags (`set_flag`, `add_counter`); outcomes that come from a fight or scene (cup won, Ashgrove defeated, key losses, and so on) are listed per theme in `battleFlags` for the runtime to set when those scenes run. A flag nobody set counts as 0 / false.
- **Code**: `core/story2/themes.ts` (`resolveThemeEnding`, `validateTheme`, `reachableEndings`). `reachableEndings` is the "plays to every ending" sim: a search over every choice of every event of the card, with battle flags free; a row hidden behind an easier row above it is reported unreachable. New gate `story-theme-audit` runs `validateTheme` on every card. Story gates: twist clue check now covers `twists`; theme endings count as reachable through their own table.
- **Director**: the drawn theme's events are favoured (`balance.story.themeEventWeight` 4) and another theme's events are never offered. Four themes now share the draw by weight 1.
- **Text** moved to `src/data/story/text/themes.json` (merged with `en.json` at load; `text.themes` has its own 0.1 MB budget) so parallel slices do not fight over `en.json`.
- **Saves**: none bumped. Tests: `tests/unit/storyThemes.test.ts`, `storyGates.test.ts`.
- **Limits (later slices)**: a reached Stop still plays its category line; running the card's events and setting the battle flags is S5 and S12. The Director does not yet filter themes by backstory fit (inputs carry no backstory). Journal tab screens are S13. The Mythic Equation has no design-doc Journal tab, so its 3 templates are new text. Journal templates use only the known tokens, so the design's `{hour}`/`{day}` style tokens were reworded.
- **Rivals (S10 wiring)**: the Director takes a theme's Primary, Secondary and Friendly rivals from the S10 table (`rolesForTheme`) when it has a row; the card audit checks the row exists. Playing the rival scenes on the theme beat sheets is S5/S12.
